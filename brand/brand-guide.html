05 — Como Usar em Outro Projeto
No HTML
  • Adicione <link rel="stylesheet" href="tokens.css"> no <head>
  • Use as classes utilitárias: j-cta, j-label, j-display
  • Use as variáveis CSS: var(--j-verde), var(--j-ouro)
No Canva
  • Verde floresta: #4A5E3A
  • Ouro: #B8935A
  • Carvão (texto): #2A2318
  • Marfim (fundo): #FAF6EE
  • Título: Cormorant Garamond 500
  • Corpo: Lora Regular
  • Labels: Raleway 700 maiúsculo
No Instagram
  • Fundo principal: Marfim #FAF6EE
  • Fundo alternativo: Carvão #2A2318
  • Texto em destaque: Cormorant Garamond itálico
  • Labels: Raleway maiúsculo com espaçamento
  • Elemento decorativo: diamante ◆ em ouro
No Figma / Adobe
  • Importe o arquivo tokens.css como base
  • Crie estilos de cor com cada hex
  • Fontes: instale via Google Fonts
  • Logo: importe logo.svg e logo-escuro.svg
  • Ornamento: quadrado 7×7px rotacionado 45° em ouro
